# ecommerce‑data‑analysis
电商用户行为数据分析与可视化项目

## 项目简介
基于公开电商数据集，完成完整的数据清洗、探索性数据分析与可视化，挖掘用户消费行为特征，输出业务分析结论。

**技术栈**：Python、Pandas、NumPy、Matplotlib、Seaborn

### 数据集说明
原始数据集文件体积较大，未上传仓库，本地运行请自行下载对应数据集。

## 项目主要工作
1. 数据清洗：处理缺失值、异常值，完成格式转换、无效数据筛选
2. 探索性数据分析：统计用户购买分布、消费金额、时间维度特征
3. 可视化分析：绘制箱线图、热力图、饼图、词云等多类统计图表
4. 分析用户消费规律，输出面向业务的优化参考建议

## 运行环境
Python >=3.9
依赖库：pandas, numpy, matplotlib, seaborn

## 项目目录说明
- src：存放项目主程序代码 main.py
- images：存放项目生成的全部可视化图表
- report：存放完整项目分析报告文档
